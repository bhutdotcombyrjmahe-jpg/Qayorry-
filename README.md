# Qayorra Fragrance by Mahe — সম্পূর্ণ ই-কমার্স ওয়েবসাইট

এটি একটি **সম্পূর্ণ, রান-করা যায় এমন** ই-কমার্স ওয়েবসাইট (শুধু ডিজাইন/ল্যান্ডিং পেজ নয়) — Node.js + Express ব্যবহার করে তৈরি, যাতে প্রোডাক্ট, অর্ডার এবং কাস্টমারের তথ্য একটি রিয়েল সার্ভারে জমা থাকে (তাই আপনি প্রোডাক্ট যোগ করলে সব ভিজিটর তা দেখতে পাবে — শুধু আপনার ব্রাউজারে না)।

## যা যা আছে

- **হোম পেজ**: অটো-স্লাইডিং প্রোডাক্ট ব্যানার (ছবিতে ক্লিক করলে প্রোডাক্ট পেজে যায়), সব প্রোডাক্টের গ্রিড (ছবি, রেটিং, দাম, টাইটেল, বিবরণ)
- **৩-ডট মেনু**: হোম, কার্ট, অর্ডার লগইন, এডমিন লগইন, এডমিন ড্যাশবোর্ড, Clients History, পলিসি
- **প্রোডাক্ট পেজ**: বিস্তারিত বিবরণ, quantity selector, Add to Cart, Order Now
- **কার্ট ও চেকআউট**: নাম/ফোন/ঠিকানা ফর্ম, ঢাকা ৳100 / বাইরে ৳150 ডেলিভারি চার্জ, Full COD, ৭ দিন রিটার্ন
- **Thank You পেজ** অর্ডার কনফার্মের পর
- **এডমিন প্যানেল** (`/admin.html`): প্রোডাক্ট যোগ/রিমুভ করা যায় (ছবি আপলোডসহ) — সাথে সাথে ওয়েবসাইটে দেখা যাবে
- **এডমিন ড্যাশবোর্ড** (`/dashboard.html`): মোট প্রোডাক্ট, আজকের ভিজিটর, আজকের অর্ডার সংখ্যা, না কিনে চলে যাওয়া ভিজিটরের সংখ্যা ইত্যাদি
- **অর্ডার প্যানেল** (`/orders.html`): সব নতুন অর্ডার দেখা যায়, রিমুভ করা যায়, ডেলিভারি মার্ক করলে Clients History-তে চলে যায়
- **Clients History** (`/clients.html`): ডেলিভারি সম্পন্ন হওয়া সব কাস্টমারের নাম, ফোন, ঠিকানা
- **WhatsApp ও Facebook ফ্লোটিং বাটন**, পলিসি পেজ

## কীভাবে চালাবেন (Run করবেন)

আপনার কম্পিউটারে [Node.js](https://nodejs.org) ইনস্টল থাকতে হবে (v18 বা তার উপরে)।

```bash
# ১. এই ফোল্ডারে যান
cd qayorra

# ২. প্রয়োজনীয় প্যাকেজ ইনস্টল করুন
npm install

# ৩. সার্ভার চালু করুন
npm start
```

এরপর ব্রাউজারে যান: **http://localhost:3000**

## হোস্টিং / লাইভ করার জন্য

এই কোড যেকোনো Node.js সাপোর্ট করা হোস্টিং-এ আপলোড করা যাবে (যেমন: Render, Railway, VPS, cPanel Node হোস্টিং ইত্যাদি)। শুধু `npm install` করে `npm start` চালাতে হবে। ডোমেইন যুক্ত করলেই ওয়েবসাইট লাইভ হয়ে যাবে।

## গুরুত্বপূর্ণ নোট

- সব ডেটা (প্রোডাক্ট, অর্ডার, ক্লায়েন্ট, ভিজিট/পারচেজ স্ট্যাটস) `data/db.json` ফাইলে সেভ হয় — সার্ভার রিস্টার্ট করলেও ডেটা হারাবে না।
- প্রোডাক্ট ইমেজ `public/uploads/` ফোল্ডারে সেভ হয়।
- লগইন টোকেন সার্ভার মেমোরিতে থাকে — সার্ভার রিস্টার্ট করলে সবাইকে আবার লগইন করতে হবে (নিরাপত্তার জন্য এটি স্বাভাবিক আচরণ)।
- "না কিনে চলে যাওয়া ভিজিটর" সংখ্যাটি একটি approximate/আনুমানিক হিসাব — যখন কেউ পেজ ছেড়ে যায় অথচ অর্ডার করেনি, তখন এটি গণনা হয়।
